# Case 02 — 학습 / 드라이버

캐글: [spscientist/students-performance-in-exams](https://www.kaggle.com/datasets/spscientist/students-performance-in-exams)  
입수: GitHub 미러 `StudentsPerformance.csv` (1,000행, 학생당 1행)

## 분석 설계 메모

- 질문: 시험 점수에 영향을 주는 요인 중 개입 가능한 것은 무엇인가
- 도메인 / 분석 단위: 학습 / 학생(단면)
- 독자: 교육 과정 담당자
- 채택 기법: 드라이버 분석(집단 평균 차이 + 층화)
- 탈락 기법과 이유: 개인 학습 궤적 — 시점·반복 관측·학생 ID 없음. 퍼널 — 단계 없음. 점수 예측 모델 — 개입 지점보다 정확도가 앞에 올 위험이 있음
- 종속변수: 수학·읽기·쓰기 평균 점수(0–100). 과목별로 차이가 뒤집히면 과목 점수도 본다
- 설명변수 (개입 / 맥락 / 제외): 개입 — 시험 준비 과정 이수. 맥락 — 점심 유형(SES 대리), 성별, 부모 학력. 제외 — 인종/민족 그룹을 바꿀 레버로 쓰지 않음
- 비교 대상(베이스라인): 전체 평균 67.8점, 준비 과정 미이수 집단
- 검증 방법: 70/30 홀드아웃에서 준비 과정 점수 차이가 남는지, 점심·성별 층에서도 같은 방향인지
- 이번엔 하지 않을 것: 개인 맞춤 경로 추천, 부모 학력을 바꾸라는 권고
- 가정: 준비 과정 이수는 선택이며, 이미 동기가 높은 학생이 이수했을 수 있다

## 한눈에 보기

- 결정 또는 질문: 당장 손댈 수 있는 학습 개입은 무엇인가
- 핵심 결과: 시험 준비 과정을 마친 학생은 평균이 7.6점 높다(72.7 vs 65.0). 점심 유형 차이(8.6점)가 더 크지만, 그건 가정 배경 대리 지표에 가깝다.
- 근거 강도: 중간 — 성별·점심 층에서는 차이가 7–9점으로 남는다. 홀드아웃에서는 5.5점으로 줄어든다.
- 다음에 할 일: 준비 과정 미이수 학생에게 이수를 늘리는 실험을 우선한다. 부모 학력·점심 유형을 바꾸라는 처방으로 가지 않는다.

## 대중용 한 줄

시험 준비 수업을 마친 학생은 평균 점수가 약 8점 높았습니다. 가정 환경 차이도 보이지만, 학교에서 바로 손댈 수 있는 것은 준비 수업 참여입니다. 수업을 들은 학생이 원래부터 준비가 되어 있었을 수 있어, 수업이 점수를 올렸다고 단정하지는 않습니다.

## 무엇을 봤는가

- 한 행이 학생 한 명이라 개인 추적은 탈락했다.
- 전체 평균 67.8점. 준비 과정 이수 358명 72.7점, 미이수 642명 65.0점.
- 쓰기 +9.9, 읽기 +7.4, 수학 +5.6으로 과목마다 크기는 다르다. 방향은 같다.
- 무료/할인 점심 안에서도 이수 차이가 +8.8점, 일반 점심에서는 +7.2점이다.
- 70% 구간 +8.5점, 나머지 30% +5.5점.

## 그것이 뜻하는 바

추정: 과정에서 바로 늘릴 수 있는 레버는 준비 과정 이수율이다. 점심 격차가 더 커 보여도, 그건 소득·지원 구조를 가리키는 맥락이지 단기간 수업 개입이 아니다. 홀드아웃에서 효과가 줄어든 것은 이 차이가 안정된 인과 효과가 아니라 표본에 민감한 연관임을 뜻한다.

## 한계

- 이수가 점수를 올렸다기보다, 준비된 학생이 과정을 끝냈을 수 있다.
- 개인별 학습 기록은 이 데이터에 없다.
- 인종/민족 평균 차이는 개입 권고로 쓰지 않았다.

## 다음에 확인할 것

- 준비 과정을 무작위에 가깝게 배정하거나, 이수 전후 점수가 있는 데이터
- 수학처럼 차이가 작은 과목은 별도 개입이 필요한지
