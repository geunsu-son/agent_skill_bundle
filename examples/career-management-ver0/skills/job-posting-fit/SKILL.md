# Job Posting Fit

## 상태

`ver0` 예시. 실제 JD 분석을 통해 적합도 표현과 갭 우선순위를 수정할 예정입니다.

## 목적

특정 **채용 공고(JD)**와 요청자의 이력·강점·어필 포인트를 대조하여 **적합도**, **강점 매칭**, **갭**, **지원 전략**을 정리합니다.

## 사용 시점

- 특정 공고에 지원하기 전 fit 확인
- “이 공고에 나갈 만한가?” 질문
- `learning-path-planning`·`profile-optimization` 전 갭 입력이 필요할 때
- `interview-story-crafting` 전 공고 키워드·요구 역량 정리

## 관련 Rule·Skill

- Rule: [`rules/career-management.mdc`](../../rules/career-management.mdc)
- [`resume-strength-discovery`](../../skills/resume-strength-discovery/SKILL.md)
- (선택) [`career-market-research`](../../skills/career-market-research/SKILL.md)

## 입력

- JD 텍스트 또는 URL (URL이면 내용 확인 가능 시 열람)
- 이력서·경력 정보
- (선택) `resume-strength-discovery` 출력
- 지원 의지·제약 (예: 즉시 지원 / 1개월 후, 비공개 이직)

JD가 없으면 Skill을 중단하지 않고, 목표 직무 설명만으로 **가상 JD 가정**을 명시한 제한적 분석을 수행할 수 있습니다.

## 절차

### 1. JD 구조화

다음을 추출합니다.

- 역할·레벨·조직 맥락
- 필수·우대 요구 (스킬, 경력 연수, 도메인, 학위·자격)
- 책임·성과 기대
- 소프트 스킬·협업·리더십 신호
- 키워드 (ATS·면접에서 반복될 가능성)

### 2. 이력·강점 매칭

| 유형 | 설명 |
|---|---|
| **직접 매칭** | JD 요구와 이력 증거가 명확히 일치 |
| **전이 매칭** | 다른 맥락이지만 같은 역량을 보여줌 |
| **부분 매칭** | 관련은 있지만 깊이·규모·기간이 약함 |
| **갭** | JD에 있지만 이력에서 확인되지 않음 |
| **초과** | JD 이상이지만 차별화 가능한 강점 |

이력에 없는 경험은 매칭하지 않습니다.

### 3. 적합도 평가

Rule과 같이 **합격 보장·정밀 확률**을 쓰지 않습니다.

- **전체 적합도**: 높음 / 중간 이상 / 중간 / 낮음 (근거 2~3문장)
- **지원 권장**: 지원 권장 / 조건부 지원 / 보완 후 지원 / 비권장 (각각 조건 명시)
- **차별화 포인트**: 이 공고에서 특히 강조할 어필 2~4개
- **리스크**: 면접·서류에서 질문받을 갭 2~4개

### 4. 지원 전략

- 이력서·자기소개서·포트폴리오에서 **위에 올릴 내용**
- JD 키워드를 **사실 범위 내** 반영할 표현 힌트
- 갭에 대한 **솔직한 프레임** (학습 중, 전이 가능 경험 연결) — 허위 서술 금지
- 다음 Skill 연계: `profile-optimization`, `interview-story-crafting`, `learning-path-planning`

## 출력 형식

```md
## 공고 요약

- 회사·역할·레벨 (JD에서 확인된 범위)
- 핵심 요구 3~5개

## 적합도

- 전체: 높음 / 중간 이상 / 중간 / 낮음
- 지원 권장: ... (조건)
- 핵심 근거:

## 매칭 매트릭스

| JD 요구 | 매칭 유형 | 이력 근거 | 비고 |

## 차별화·어필 포인트

## 갭·리스크

## 지원 전략

## 다음 Skill

## 가정·한계
```

## 완료 조건

- JD 요구가 구조화됨
- 매칭이 이력 근거와 연결됨
- 허위 매칭·합격 보장 없음
- 지원 권장에 조건이 있음
- 실행 가능한 지원 전략이 포함됨

## 향후 Script 후보

- JD URL → 구조화 JSON
- 키워드 빈도 vs 이력 키워드 스코어
