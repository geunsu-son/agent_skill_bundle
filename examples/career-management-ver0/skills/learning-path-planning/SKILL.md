# Learning Path Planning

## 상태

`ver0` 예시. 실제 갭·기간 제약 피드백으로 우선순위 프레임을 수정할 예정입니다.

## 목적

목표 커리어·JD·갭 분석 결과를 바탕으로 **학습·프로젝트·실습** 우선순위와 실행 가능한 경로를 설계합니다.

## 사용 시점

- 스킬 갭이 확인된 후 “무엇부터 공부할까?”
- `job-posting-fit`·`resume-strength-discovery` 후 보완 계획
- 커리어 전환·레벨업 준비 기간이 정해져 있을 때

## 관련 Rule·Skill

- Rule: [`rules/career-management.mdc`](../../rules/career-management.mdc)
- [`job-posting-fit`](../../skills/job-posting-fit/SKILL.md) 또는 갭 목록
- (선택) [`career-market-research`](../../skills/career-market-research/SKILL.md)
- (선택) [`resume-strength-discovery`](../../skills/resume-strength-discovery/SKILL.md)

## 입력

- 목표 직무·커리어 목표
- 갭 목록 (또는 JD·이력으로 Skill 내에서 도출)
- 가용 시간 (주 N시간)
- 기간 (예: 3개월, 6개월)
- 선호 학습 방식 (강의 / 책 / 프로젝트 / 오픈소스 / 자격증)
- 제약 (비용, 영어, 야간만 가능 등)

## 절차

### 1. 갭 우선순위

갭을 다음으로 분류합니다.

| 우선순위 | 기준 |
|---|---|
| **P0** | JD·목표 직무에서 필수, 면접·서류에서 즉시 질문될 가능성 높음 |
| **P1** | 강한 차별화 또는 전이 매칭을 강화 |
| **P2** | 중장기, 또는 이미 학습 중인 것과 시너지 |

각 갭에 **이력에서 전이 가능한지** 짧게 메모합니다.

### 2. 학습 vs 프로젝트 vs 실무

갭 유형에 맞는 **가장 빠른 신호**를 선택합니다.

- **지식 갭** → 구조화 학습 + 작은 실습
- **도구·스택 갭** → 튜토리얼 + 미니 프로젝트
- **경험·도메인 갭** → 사이드 프로젝트, 오픈소스, 내부 과제, 스테이징 경험
- **신뢰·레벨 갭** → 리드 역할, 규모, 수치가 나는 산출물

허위 경력을 만들지 않고 **검증 가능한 산출물**을 목표에 넣습니다.

### 3. 단계별 플랜

기간에 맞춰 **주차 또는 월 단위** (과도한 일일 스케줄은 ver0에서 생략 가능):

- Phase 1: P0 집중
- Phase 2: P1 + 포트폴리오·이력 반영
- Phase 3: (기간 허용 시) P2·심화

각 단계에:

- 목표 (측정 가능)
- 추천 리소스 **유형** (특정 강의명을 단정하지 않고, 검색 키워드·플랫폼 유형)
- 산출물 (README, 데모 URL, 블로그, PR 등)
- `profile-optimization`·`portfolio-site-build` 연계 시점

### 4. 리스크·현실 점검

- 기간 내 P0 전부가 비현실적일 때 **축소안**
- “이 공고는 보완 후 지원” vs “다른 공고 병행” 권장
- 번아웃 방지: 주당 시간 상한 제안

### 5. 완료 정의

각 P0 갭에 “이 정도면 이력·면접에 말할 수 있다”는 **완료 조건**을 명시합니다.

## 완료 조건

- 갭이 우선순위와 완료 정의를 가짐
- 기간·시간 제약이 반영됨
- 산출물이 검증 가능하고 허위 경력을 요구하지 않음
- 비현실적 계획 시 축소안이 있음
- 리소스는 유형·키워드 수준 (무근거 특정 강의 단정 최소화)

## 향후 Script 후보

- 갭 리스트 → 주차 캘린더 템플릿
- 학습 진행 체크리스트
