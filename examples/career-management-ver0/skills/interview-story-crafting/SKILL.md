# Interview Story Crafting

## 상태

`ver0` 예시. 실제 면접 준비 피드백으로 스토리 길이·톤을 수정할 예정입니다.

## 목적

이력·경험을 **STAR**(Situation, Task, Action, Result) 및 **행동면접**에 쓸 수 있는 스토리로 구조화하고, 예상 질문과 연결합니다.

## 사용 시점

- 면접 준비, 행동면접·과거 경험 질문 대비
- 자기소개·“가장 어려웠던 경험” 등 답변 초안
- `job-posting-fit` 후 공고 맥락에 맞는 스토리 선별

## 관련 Rule·Skill

- Rule: [`rules/career-management.mdc`](../../rules/career-management.mdc)
- [`resume-strength-discovery`](../../skills/resume-strength-discovery/SKILL.md)
- (선택) [`job-posting-fit`](../../skills/job-posting-fit/SKILL.md)

## 입력

- 이력·경험 서술 (이력서 또는 구두 설명)
- 목표 직무·면접 유형 (기술 / 행동 / 혼합)
- (선택) JD·`job-posting-fit` 결과
- (선택) 강조하고 싶은 어필 포인트
- 답변 길이 선호 (30초 / 1분 / 2분)

## 절차

### 1. 스토리 소재 선별

이력에서 **구체적 행동·결과**가 있는 경험만 후보로 합니다.

- 리드·협업·문제 해결·실패·학습·우선순위·갈등·기술적 난이도
- 각 후보에 **증거 강도** (높음/중간/약함) 표시
- 없는 경험은 스토리로 만들지 않습니다.

### 2. STAR 구조화

각 스토리 (1~2분 말하기 분량 목표):

| 단계 | 내용 |
|---|---|
| **S** | 상황·맥락 (짧게) |
| **T** | 나의 책임·목표 |
| **A** | 구체적 행동 (복수 가능) |
| **R** | 결과·학습 (정량 있으면 포함, 없으면 정성·범위) |

- “우리 팀이”만 말하고 **내 행동**이 없는 스토리는 A를 보강하거나 후순위
- 과장·허위 없이, 이력 범위 내 표현

### 3. 질문 매핑

공통·직무 관련 예상 질문에 스토리를 연결합니다.

예: 리더십, 실패, 우선순위, 기술적 도전, 협업, 고객/비즈니스 임팩트, 전환·학습

JD가 있으면 JD 키워드·갭 관련 질문을 추가합니다.

### 4. 압축·확장 버전

- **30초**: S+T 한 줄, A 핵심 1~2, R 한 줄
- **1분**: STAR 균형
- **2분**: 맥락·트레이드오프·반성 (해당 시)

### 5. 피해야 할 표현·보완

- 모호한 “열정”, “커뮤니케이션 좋음”만 있는 답변 → 구체 행동으로 교체 제안
- 갭 질문 예상 시: `job-posting-fit` 갭과 연계한 **솔직한 답변 프레임** (허위 경력 아님)

## 출력 형식

```md
## 스토리 목록

### 스토리 1: (제목)
- 어필 포인트:
- 증거 강도:
- STAR (1분):
- 30초 / 2분 변형:
- 연결 질문:

### 스토리 2: ...

## 질문 → 스토리 매핑 테이블

## 갭·어려운 질문 대비

## 확인이 필요한 정보 (경험 보강용)
```

## 완료 조건

- 스토리가 이력 근거에 기반함
- STAR에 구체적 Action 포함
- 길이 변형이 있음 (또는 요청 길이에 맞춤)
- 허위·과장 스토리 없음
- JD/직무와 연결됨 (입력 있을 때)

## 향후 Script 후보

- STAR 템플릿 Markdown 생성
- JD 키워드 → 추천 스토리 태그
