# Networking Outreach

## 상태

`ver0` 예시. 실제 메시지 피드백으로 톤·길이 가이드를 수정할 예정입니다.

## 목적

커피챗 요청, 추천·소개 요청, 지원 후 팔로업, LinkedIn 연결 메시지 등 **네트워킹 아웃리치** 초안을 작성합니다.

## 사용 시점

- 타겟 회사·직무에 연락하기 전
- 리크루터·팀 멤버·전 동료에게 소개 요청
- 지원 후 follow-up
- `job-posting-fit` 후 특정 공고·팀 맥락이 있을 때

## 관련 Rule·Skill

- Rule: [`rules/career-management.mdc`](../../rules/career-management.mdc)
- (선택) [`job-posting-fit`](../../skills/job-posting-fit/SKILL.md)
- (선택) [`resume-strength-discovery`](../../skills/resume-strength-discovery/SKILL.md)
- (선택) [`profile-optimization`](../../skills/profile-optimization/SKILL.md)

## 입력

- 아웃리치 유형: 커피챗 / 추천 요청 / 소개 요청 / follow-up / LinkedIn 연결
- 대상 (역할·관계: 모름 / 1촌 / 전 동료 / 리크루터 등)
- 목표 (정보 수집 / 면접 기회 / 추천 / 관계 유지)
- (선택) 회사·팀·공고 맥락
- (선택) 나의 한 줄 포지셔닝·어필 포인트 1~2개
- 톤: 격식 / 간결 / 한국어 / 영어
- 길이: 짧음 (3~5문장) / 중간

## 절차

### 1. 메시지 전략

- **목적 한 줄**: 상대가 응답할 이유
- **공통점·맥락**: 왜 이 사람에게 (과도한 칭찬·사칭 금지)
- **부담 최소화**: 시간·선택권 (“괜찮으시면”, “15분”)
- **허위 관계·허위 추천 암시 금지**

### 2. 유형별 초안

각 유형에 **제목(해당 시) + 본문** 초안:

| 유형 | 핵심 |
|---|---|
| 커피챗 | 구체 질문 1~2개, 시간 옵션 |
| 추천 요청 | 관계·근거, 지원 맥락, 상대 부담 줄이기 |
| 소개 요청 | 누구에게·왜, 이미 한 일(지원·조사) |
| Follow-up | 지원 일·포지션, 가치 추가 한 줄 |
| LinkedIn 연결 | 300자 내, 포지셔닝 한 줄 |

### 3. 변형

- 더 짧은 버전
- 더 격식 / 더 캐주얼 (요청 시)

### 4. 피해야 할 것

- 장문 자기 PR
- 합격·추천 압박
- 거짓 “오랜 관심” (근거 없을 때)
- 스팸성 동일 메시지 대량 발송 권장

### 5. follow-up 타이밍 (가이드)

- 1차 후 5~7영업일 등 **일반적 가이드** (상황 가정 명시)
- 2차 follow-up은 더 짧게

## 출력 형식

```md
## 아웃리치 전략

- 유형 / 대상 / 목표
- 맥락·공통점:

## 메시지 초안

### (유형) — 표준
제목:
본문:

### 짧은 버전

### (선택) follow-up / 2차

## 커스터마이즈 포인트

- 상대 이름·회사·구체 질문 넣을 자리

## 피할 표현·윤리 체크

## follow-up 타이밍 (가정)
```

## 완료 조건

- 유형에 맞는 초안이 있음
- 부담 최소화·구체 목적이 포함됨
- 허위 관계·과장·압박 없음
- 톤·길이 요청 반영
- Rule 윤리 원칙 준수

## 향후 Script 후보

- 채널별 글자 수 검증 (LinkedIn 등)
- 메시지 템플릿 변수 치환
