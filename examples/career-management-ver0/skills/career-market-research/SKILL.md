# Career Market Research

## 상태

`ver0` 예시. 실제 상담을 통해 조사 범위와 출처 표기를 수정할 예정입니다.

## 목적

요청자의 **목표 커리어**(직무·산업·레벨·지역)에 맞춰 최신 트렌드, 채용 시장에서 강조되는 포인트, 요구 역량을 조사하고 정리합니다.

## 사용 시점

- 커리어 상담 전 시장 맥락이 필요할 때
- 이력·강점 분석 전 “무엇이 지금 중요한지” 기준을 잡을 때
- 특정 직무·산업으로 전환을 준비할 때

## 입력

- 목표 직무·역할 (예: 백엔드 엔지니어, PM, 데이터 분석가)
- 산업·도메인 (선택)
- 경력 레벨 (주니어·미드·시니어 등, 가능하면)
- 지역·근무 형태 (선택: 국내, 원격, 특정 도시)
- 조사 시점 (실행 시각)

목표 직무가 없으면 상담을 중단하지 않고, 요청자가 제공한 맥락에서 **가장 가까운 가정**을 명시한 뒤 조사합니다.

## 절차

### 1. 조사 범위 정의

다음 중 상담에 필요한 항목만 선택합니다.

- 채용 공고에서 반복되는 스킬·경험 요구
- 업계 뉴스·리포트·컨퍼런스·오픈소스·제품 동향
- 역할 정의 변화 (직무명·스킬 스택·협업 방식)
- 자주 언급되는 도구·자격·프로젝트 유형
- 지역·산업 특수 요구 (가능한 경우)

### 2. 최신 정보 수집

- 웹 검색 등 사용 가능한 도구로 공개 자료를 확인합니다.
- 채용 플랫폼·기업 채용 페이지·업계 매체·공식 문서를 우선합니다.
- 단일 출처만으로 시장 전체를 단정하지 않습니다.
- 조사 시점을 기록합니다.

### 3. 사실·관측·해석 구분

| 구분 | 예시 |
|---|---|
| 사실 | 특정 공고에 명시된 요구 스킬 |
| 관측 | 최근 N건 공고·기사에서 반복 등장 |
| 해석 | “향후 더 중요해질 가능성” |

### 4. 강조 포인트 추출

다음 형식으로 3~7개로 압축합니다.

- **핵심 역량**: 역할 수행에 반복 요구되는 것
- **차별화 신호**: 같은 레벨 지원자 중 드물게 보이는 것
- **빠르게 변하는 영역**: 단기간 내 우선 확인이 필요한 것
- **과대평가·과소평가**: 말은 많지만 실제 공고·실무와 어긋날 수 있는 것 (가능한 경우)

### 5. 이력 분석과의 연결 힌트

트렌드만 나열하지 않고, 이후 `resume-strength-discovery`에서 매칭할 때 쓸 **검색 키워드·경험 유형**을 짧게 적습니다.

## 출력 형식

```md
## 조사 개요

- 목표 커리어: ...
- 범위: 직무 / 산업 / 레벨 / 지역
- 조사 시점: ...
- 가정: (목표가 불명확했을 경우)

## 지금 강조할 트렌드·포인트

1. ... — [사실|관측|해석], 출처 유형
2. ...

## 채용 시장에서 자주 보이는 요구

- 스킬·경험:
- 도구·자격:
- 소프트 스킬·협업:

## 차별화·변화 신호

## 이력 매칭 시 확인할 키워드

## 출처·한계

- 사용한 출처 유형과 시점
- 조사가 커버하지 못한 범위
```

## 완료 조건

- 목표 커리어(또는 가정)가 명시됨
- 조사 시점이 기록됨
- 사실·관측·해석이 구분됨
- 강조 포인트가 3~7개로 압축됨
- 출처 유형 또는 한계가 명시됨
- 이력 매칭용 키워드 힌트가 포함됨

## 향후 Script 후보

- 채용 공고 키워드 빈도 집계
- 직무·지역별 요구 스킬 정규화
- 트렌드 조사 결과 저장·시점 비교
