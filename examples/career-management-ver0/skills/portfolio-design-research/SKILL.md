# Portfolio Design Research

## 상태

`ver0` 예시. 실제 포트폴리오 제작을 통해 디자인 스펙 형식을 수정할 예정입니다.

## 목적

포트폴리오를 **단일 공용 템플릿**으로 만들지 않도록, 목표 커리어·개인 톤·참고 브랜드·다크/라이트 선호를 조사하고 **디자인 방향·디자인 시스템 초안**을 정의합니다.

## 사용 시점

- `portfolio-site-build` 구현 전 (필수 선행)
- “느낌만 비슷하게”, “다크 모드”, “○○ 브랜드 톤” 요청
- 이력·어필 포인트에 맞는 시각적 계층이 필요할 때

## 관련 Rule·Skill

- Rule: [`rules/career-management.mdc`](../../rules/career-management.mdc)
- (선택) [`resume-strength-discovery`](../../skills/resume-strength-discovery/SKILL.md) — 강조할 콘텐츠 우선순위
- (선택) [`career-market-research`](../../skills/career-market-research/SKILL.md) — 직무·산업 톤

## 입력

- 목표 커리어·지원 직무
- 선호: 다크 / 라이트 / 자동(시스템) / 둘 다 지원
- 톤·무드 (예: 미니멀, 테크니컬, 따뜻한, 권위적, 실험적)
- 참고 브랜드·사이트·제품 (URL 또는 이름)
- 피하고 싶은 스타일 (선택)
- 이력·어필 포인트·필수 섹션 (선택)
- 접근성·가독성 우선 여부 (선택)

## 절차

### 1. 콘텐츠·메시지 우선순위

디자인 전에 **무엇을 먼저 보여줄지** 정합니다.

- 한 줄 포지셔닝 (헤드라인)
- 상단에 올 어필 포인트 2~4개
- 프로젝트·경력·스킬·연락의 우선순위
- `resume-strength-discovery` 결과가 있으면 반영

### 2. 참고·톤 조사

- 사용자가 준 참고 URL·브랜드를 확인합니다 (웹 검색·사이트 열람 가능 시).
- 참고에서 **복사할 요소**와 **복사하지 않을 요소**를 구분합니다.
  - 복사 가능: 색 대비, 타이포 계층, 여백 리듬, 인터랙션 톤
  - 피함: 로고·일러스트·고유 자산 무단 유사, 과도한 장식
- 목표 직무·산업에 어긋나는 톤(너무 캐주얼/너무 화려 등)을 짚습니다.

### 3. 디자인 방향 정의

다음을 명시합니다.

- **무드 한 줄**
- **다크/라이트**: 기본 모드, 전환 방식(토글 / CSS만 / 없음)
- **타이포**: 제목·본문·코드(해당 시)의 계층 — 구체 폰트는 스택·웹폰트 가능 범위 내 제안
- **색**: 배경·표면·텍스트·강조·링크 — 의미 단위(성공 아님, **계층·CTA**)
- **레이아웃**: 단일 페이지 스크롤 / 멀티 페이지 / 사이드 네비 등
- **모션**: 없음 / 미세(hover·focus) / 과하지 않은 전환
- **차별화 포인트**: 이 사이트만의 한 가지 시각·구조적 특징 (템플릿과 동일해지지 않게)

### 4. 디자인 시스템 초안 (구현용)

코드로 옮길 수 있는 수준으로 정리합니다.

```text
tokens: color, spacing, radius, shadow, font-size scale
components: header, section, project-card, tag, link, footer (필요한 것만)
breakpoints: mobile-first 기준
a11y: 대비, focus ring, heading order
```

Next.js면 CSS 변수·Tailwind 테마·컴포넌트 props로 매핑할 항목을 적습니다.
HTML 경로면 `:root` CSS 변수와 클래스 이름 규칙을 적습니다.

### 5. 금지·가정

- 단일 “기본 포트폴리오” 레이아웃을 그대로 쓰지 않음을 명시
- 참고가 없을 때의 가정 (직무 기반 기본 톤)
- 이미지·로고·일러스트가 없을 때의 대안 (타이포·레이아웃으로 차별화)


## 완료 조건

- 콘텐츠 우선순위가 디자인보다 먼저 정리됨
- 다크/라이트·톤·참고 브랜드가 반영되거나 가정이 명시됨
- 구현 가능한 tokens·components 초안이 포함됨
- “기본 템플릿 일괄 적용”을 피하는 차별화 포인트가 1개 이상 있음
- 참고 브랜드 무단 복제를 권장하지 않음

## 향후 Script 후보
