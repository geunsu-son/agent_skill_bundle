# 스타일 근거

`profile.md`의 각 지시에 짧은 인용을 붙인다. 글 전문을 여기 복사하지 않는다.

| 축 | 주장 | 구분 | 인용 | 글 id 또는 제목 |
|---|---|---|---|---|
| 말투 |  | 사실 / 관찰 / 가정 | 한두 문장 |  |
| 호흡 |  |  |  |  |
| 도입 |  |  |  |  |
| 맺음 |  |  |  |  |
| 제목 |  |  |  |  |
| 하지 않는 것 |  |  | (없으면 “표본 N편에서 0회”) |  |

구분:

- **사실**: 표본 대부분에서 동일
- **관찰**: 경향이지만 예외가 있음
- **가정**: 편수가 부족하거나 한쪽 시리즈에만 해당
