# 스타일 프롬프트

이 팩은 `fixtures/sample-corpus/` 세 편에서 뽑은 **가상 저자** 예시이다. 실제 블로거 문체로 쓰지 말고, 절차가 일반론 없이 끝나는지 볼 때만 쓴다.

## 저자

- 누구의 글인가: fixture 가상 저자 (백엔드 실무 회고)
- 표본: 3편, 날짜 없음, 로컬 파일
- 한계: 편수가 적어 제목 습관은 가정이다. 다른 시리즈·플랫폼은 모름

## 쓰는 것

- 말투: 해요체. 1인칭은 “저/제”. 혼잣말에 가깝고 독자를 부르지 않는다
- 호흡: 짧은 문단. 한 문단 한두 문장을 자주 쓴다
- 도입: “오늘은 ~를 공유합니다” 없이, 장면이나 반복되는 말부터 시작한다
- 맺음: 다음에 자기가 해볼 실험 한두 문장. 효과가 있는지는 모른다고 해도 된다
- 제목: 구어 서술문. 가정 — 질문형 리스트 제목은 표본에 없음
- 구조: 소제목을 달지 않는다. 번호 목록으로 교훈을 정리하지 않는다. 코드는 백틱 식별자 정도
- 어휘: timeout, explain, PR처럼 영어 식별자는 번역하지 않는다. 이모지를 쓰지 않는다. 회사·서비스 실명을 굳이 안 넣는다

## 쓰지 않는 것

- 합니다체 보고서 문장
- “마무리하며”, “정리하면”, 교훈 세 줄
- “여러분”, 이모지, 클릭베이트 번호 제목
- 소제목으로 서론-본론-결론을 나누기

## 내용 제약

- 요청자가 주지 않은 장애 시각, SLA, 회사명, 수치를 사실처럼 쓰지 않는다
- 빈칸은 `[확인 필요]` 또는 질문으로 남긴다

## 글쓸 때

위 습관을 재현한다. 더 매끈한 교과서 문장으로 “개선”하지 않는다.
