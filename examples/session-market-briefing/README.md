# Session Market Briefing — ver0 Example

직장인이 시장 정보를 직접 찾아다니고 계속 후속 확인하지 않아도 되도록, 세션 시작 전에 핵심 변수와 가장 유력한 시장 방향을 정리하는 예시입니다.

이 예시는 아직 완성된 제품이 아닙니다. Rule·Skill·Automation을 실제 반복 업무에 어떻게 나눌지 살펴보기 위한 첫 작업물입니다.

## 해결하려는 문제

일반적인 경제 브리핑은 뉴스와 일정을 나열하는 데 그치는 경우가 많습니다. 사용자는 다시 정보를 해석하고 시장을 확인해야 합니다.

이 예시는 다음 질문에 답하는 것을 목표로 합니다.

1. 현재 상승·하락·횡보 중 무엇이 더 유력한가?
2. 그 판단의 핵심 근거는 무엇인가?
3. 어떤 조건에서 판단이 바뀌는가?
4. 다음 확인 시점까지 무엇만 보면 되는가?

## 구성

```text
Rule
→ 브리핑 작성자가 계속 지켜야 할 판단·표현 원칙

Skill
→ 실행 시각 확인부터 조사, 방향 판정, 출력까지의 절차

Automation
→ Skill을 언제 실행할지에 대한 예약 명세
```

- [`skills/session-market-briefing/SKILL.md`](skills/session-market-briefing/SKILL.md)

## ver0에서 일부러 하지 않은 것

- 특정 뉴스 API나 경제 캘린더 API 고정
- 시장 방향을 계산하는 정량 모델 구현
- 자산별 진입가·손절가 자동 산출
- 과거 브리핑 백테스트
- 결과 저장 및 평가 자동화

먼저 실제 브리핑에서 Rule과 Skill이 충분히 유용한지 확인한 뒤 반복 가능한 부분만 Script로 분리합니다.

## 관찰할 항목

- 브리핑이 단순 뉴스 나열에 그치지 않는가?
- 방향 판단과 근거가 서로 일치하는가?
- 유력도 표현이 과도한 확신을 만들지 않는가?
- 무효화 조건이 실제로 판단 변경에 도움이 되는가?
- 직장인이 다음 확인 전까지 볼 변수가 충분히 줄어드는가?
- 세션별 브리핑이 같은 형식을 유지하는가?

## 예시 출력 골격

```md
## 한눈에 보기

- 주 시나리오: 하락 우세
- 유력도: 중간 이상
- 핵심 이유: 달러와 단기금리 동반 상승, 위험자산의 호재 반응 약화
- 다음 확인: 핵심 지표 발표 후 금리와 주요 지지선 반응

## 시장 환경

사실과 관찰을 간단히 정리한다.

## 시나리오 순위

1. 하락 — 중간 이상
2. 횡보 — 중간
3. 상승 — 낮음

## 판단 변경 조건

주 시나리오가 무효화되는 조건을 작성한다.

## 다음 확인 전 볼 것

확인할 변수 2~4개만 남긴다.
```

> 예시는 판단을 대신 확정하는 시스템이 아니라, 사용자가 확인해야 할 정보와 판단 비용을 줄이는 보조 도구입니다.
