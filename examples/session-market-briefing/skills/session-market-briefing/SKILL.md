# Session Market Briefing

## 상태

`ver0` 예시. 실제 반복 사용을 통해 단계와 출력 형식을 수정할 예정입니다.

## 목적

현재 실행 시각에 맞는 트레이딩 세션을 식별하고, 최신 거시경제·정책·시장 정보를 조사해 직장인이 빠르게 판단할 수 있는 세션 브리핑을 작성합니다.

브리핑은 가능한 시나리오를 모두 검토하되, 상승·하락·횡보 중 가장 유력한 방향과 그 판단이 바뀌는 조건을 분명히 제시해야 합니다.

## 사용 시점

- 아시아 세션 준비
- 런던 세션 준비 또는 초기 반응 확인
- 뉴욕 세션 준비 또는 핵심 변동성 확인
- 특정 경제지표 발표 전후의 시장 환경 점검

## 입력

- 현재 실행 시각과 시간대
- 확인할 주요 자산 또는 시장
- 사용 가능한 최신 뉴스, 경제 일정, 시장 데이터
- 필요한 경우 사용자의 현재 관점이나 관심 포지션

사용자의 관점은 관심 변수를 조정하는 데만 사용하며 방향 판단 자체를 편향시키지 않습니다.

## 절차

### 1. 세션 목적 식별

현재 KST 시각을 확인하고 이번 브리핑의 목적을 정합니다.

예시:

- 07:30: 아시아 세션 준비
- 15:30: 런던 세션 준비
- 17:30: 런던 초기 반응 확인
- 20:30: 뉴욕 세션 준비
- 21:30: 뉴욕 본게임 직전
- 23:30: 뉴욕 핵심 변동성 확인

실제 Automation에 등록되지 않은 시간도 Skill 자체에서는 지원할 수 있습니다.

### 2. 최신성 확인

- 최근 주요 경제·정책·기업·지정학 뉴스를 확인합니다.
- 오늘과 다음 거래일의 경제지표, 중앙은행 발언, 국채 입찰, 고위험 이벤트를 확인합니다.
- 발표 시각은 KST로 변환합니다.
- 이미 발표된 내용과 새로 추가된 정보를 구분합니다.

### 3. 시장 반응 확인

가능한 범위에서 다음을 확인합니다.

- 달러지수 또는 주요 달러 흐름
- 미국 2년물·10년물 국채금리
- 주요 주가지수 및 선물
- 금·유가 등 핵심 원자재
- BTC·ETH 등 주요 크립토
- 호재와 악재에 대한 실제 가격 반응

### 4. 핵심 변수 선별

모든 정보를 나열하지 않습니다. 현재 세션에서 방향을 바꿀 수 있는 변수와 이미 가격에 반영된 변수를 구분합니다.

최종 브리핑에 남길 핵심 변수는 가능한 한 3~5개로 제한합니다.

### 5. 방향 판정

다음 순서로 판단합니다.

1. 거시환경이 위험선호와 위험회피 중 어디에 가까운지 평가합니다.
2. 달러, 금리, 주가지수, 원자재, 크립토의 방향이 서로 일치하는지 확인합니다.
3. 예정된 이벤트가 현재 방향을 강화하거나 뒤집을 가능성을 평가합니다.
4. 뉴스와 실제 가격 반응이 일치하는지 확인합니다.
5. 상승·하락·횡보 시나리오별 근거를 비교합니다.
6. 가장 유력한 주 시나리오를 선정합니다.
7. 유력도와 무효화 조건을 작성합니다.

세 시나리오의 근거가 비슷하거나 신호가 충돌하면 억지로 상승 또는 하락을 선택하지 않고 횡보 또는 판단 유보로 분류합니다.

### 6. 사용자 행동 비용 줄이기

다음 확인 시점까지 사용자가 볼 항목을 2~4개로 줄입니다.

예시:

- 미국 2년물 금리가 발표 후 상승분을 유지하는지
- 달러지수가 전일 고점을 돌파하는지
- ETH가 주요 지지선 아래에서 안착하는지
- 호재 발표 후 상승분을 세션 종료까지 유지하는지

### 7. 출력 작성

아래 형식을 기본으로 사용합니다.

```md
## 한눈에 보기

- 주 시나리오: 상승 / 하락 / 횡보
- 유력도: 높음 / 중간 이상 / 중간 / 낮음
- 핵심 이유: 1~2문장
- 다음 확인: 가장 중요한 이벤트 또는 가격 반응

## 주요 일정과 재료

현재 세션에 영향을 줄 일정과 뉴스를 중요도순으로 정리한다.

## 시장 반응

달러, 금리, 주가지수, 원자재, 크립토의 반응과 신호 일치 여부를 설명한다.

## 시나리오 순위

1. 주 시나리오 — 유력도와 근거
2. 대안 시나리오 — 발생 조건
3. 낮은 우선순위 시나리오 — 발생 조건

## 판단 변경 조건

주 시나리오가 무효화되거나 우선순위가 바뀌는 조건을 작성한다.

## 다음 확인 전 볼 것

사용자가 직접 확인할 변수 2~4개를 작성한다.
```

## 완료 조건

- 최신 정보와 발표 시각이 확인됨
- 사실과 해석이 구분됨
- 상승·하락·횡보를 모두 검토함
- 가장 유력한 주 시나리오를 제시함
- 유력도와 무효화 조건을 포함함
- 다음 확인 전 볼 변수를 2~4개로 줄임
- 사용자의 기존 관점에 맞춰 결론을 왜곡하지 않음

## 향후 Script 후보

- 경제 캘린더 수집 및 KST 변환
- 미국 국채금리·달러·주가지수·원자재·크립토 데이터 수집
- 발표 전후 가격 반응 비교
- 브리핑 결과 저장과 사후 평가

현재 ver0에서는 도구와 데이터 소스를 고정하지 않습니다. 실제 사용 중 반복성과 안정성이 확인된 작업부터 Script로 분리합니다.
