# 작업 아이디어 정의

## 작업 이름

도메인 기반 데이터 분석 설계와 의사결정자용 해석

## 해결하려는 문제

Agent에게 분석을 맡기면 도메인과 질문과 무관하게 같은 파이프라인(요약 통계 → 상관 → 모델 → 차트)으로 들어가는 경우가 많다.

## Agent가 수행할 작업

질문·입도에 맞는 기법을 고르고, 종속/설명변수를 설계한 뒤 검증한다. 해석·보고서는 임원진 또는 대중인지 확인된 뒤에만 쓴다.

## 기대 결과물

- Rule: 기법 선택, 변수 탐색, 검증, 독자 확인, 보고 원칙
- Skill: 설계 메모 → 실행 → 독자 gate → 보고서
