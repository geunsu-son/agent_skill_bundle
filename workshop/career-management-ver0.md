# 작업 아이디어 정의

## 작업 이름

커리어 매니지먼트 Rule·Skill (ver0)

## 해결하려는 문제

커리어 조언은 트렌드 조사, 이력 해석, 어필 포인트 정리가 한 흐름에 섞여 누락·일반론·낡은 정보가 섞일 수 있다.

## Agent가 수행할 작업

목표 커리어를 중심에 두고 시장 트렌드를 조사하고, 이력서·경험에서 강점·어필 포인트를 발굴한 뒤 실행 가능한 커리어 발전 조언을 제공한다. 필요 시 이력·포트폴리오 웹 배포(Next.js+Vercel 또는 HTML+Cloudflare)까지 연계한다.

## 기대 결과물

- Rule: 커리어 매니저 판단·표현·윤리·웹 포트폴리오 원칙
- Skill: 시장 조사, 이력·강점 발굴, 통합 상담, 웹 포트폴리오 3종, **지원·성장 6종** (job-posting-fit, interview-story-crafting, profile-optimization, learning-path-planning, networking-outreach, compensation-research)
- 예시 README와 검증·확장 Skill 후보 목록

## 가정과 아직 결정하지 못한 점

- Automation(정기 체크인)은 ver0에서 생략
- 지원·성장 6종 Skill은 분리해 두었고, 실제 연계 품질은 아직 이 저장소에서 검증하지 않음
- `.cursor/` 승격은 다른 저장소에서 번들을 사용해 본 뒤 검토

## 이 저장소 마감

- 상태: `draft` 예시 완료. 이 저장소 구현 작업은 여기서 종료
- 다음 실험: 다른 저장소에 번들을 세팅해 실행하고, 관찰 결과를 이 공방에 되돌림
