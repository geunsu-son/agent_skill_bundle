# 작업 아이디어 정의

## 작업 이름

한국어 공고문 입력 토큰 비교 (Grok 4.6 / Composer 2.5 / GPT-5.6 Luna)

## 해결하려는 문제

같은 한국어 문서를 넣어도 모델(토크나이저)마다 입력 토큰 수가 달라 비용·컨텍스트 예산을 직관으로 비교하기 어렵다. OpenAI가 Anthropic의 약 50% 수준이라는 이야기도, 지금 쓰는 세 모델에 바로 대입할 수 있는지 확인이 필요하다.

## Agent가 수행할 작업

공개 토크나이저로 동일 한국어 공고문의 입력 토큰을 세고, 의미가 같은 영어 번역과 비교한다. 비공개 토크나이저(Grok 4.6, Composer 2.5)는 같은 과제를 실제 서브에이전트로 돌려 사용량 기록이 나오는지 확인한다.

## 기대 결과물

- 공고문 전체와 한·영 대응 표본의 토큰 수
- 사용자가 쓰는 세 모델에 대한 해석(측정값 / 추정 / 미측정 구분)
- 재실행 스크립트

## 현재 방식과 불편한 점

채팅에서 모델을 바꿔 가며 체감하는 방식은 시스템 프롬프트·도구·출력 길이가 섞여 토크나이저 차이를 분리하지 못한다.

## 완료 조건

같은 PDF 텍스트에 대해 공개 토크나이저 숫자가 재현되고, 못 잰 항목이 숨겨지지 않는다.

## 가정과 아직 결정하지 못한 점

- GPT-5.6 Luna는 GPT-5.6 계열이라 `o200k_base`를 쓴다고 본다. GPT-5.6 Sol 실측과 공개 토크나이저 비교가 일치한다는 보고가 있다.
- `Xenova/claude-tokenizer`는 구형 Claude 어휘 근사치다. Claude 4.7+ 청구 기준은 이보다 더 높을 수 있다.
- Grok 4.6·Composer 2.5 토크나이저는 공개되어 있지 않다. 이 환경에는 xAI/Anthropic count API 키가 없다.
- 한·영 대응 표본의 영어는 의미 보존 번역이며, 더 짧게 옮기면 한국어 배율이 커질 수 있다.

## 상태

`draft` — 한 번 측정한 기록. 공통 Rule/Skill로 승격하지 않음.

## 관찰 (2026-09-14)

### 코퍼스

SH 제51차 장기전세주택 입주자 모집공고 PDF 64쪽. 추출 텍스트 89,705자, 한글 음절 50,514, UTF-8 193,335바이트.

### 공고문 전체 입력 토큰

| 토크나이저 | 이 저장소에서 대응하는 모델 | 토큰 | o200k 대비 |
|---|---|---:|---:|
| `o200k_base` | GPT-5.6 Luna (계열 가정) | 59,755 | 1.00× |
| `cl100k_base` | 구 GPT-4 / 3.5 | 86,215 | 1.44× |
| Xenova Claude 어휘 | 구 Claude 근사 | 94,253 | 1.58× |

한글 음절당 토큰: Luna 계열 1.18, 구 GPT-4 1.71, 구 Claude 1.87.

OpenAI 최신 토크나이저는 이 문서에서 구 Claude 근사치의 **63%**다. “50% 수준”은 Claude 4.7+처럼 더 비싼 토크나이저를 기준으로 하면 가까워진다. 외부 보고(ellamind Tokenization Tax 2026)는 Claude 4.7+가 언어 평균으로 o200k보다 약 65% 더 쓴다고 한다. 그 배율을 이 문서 o200k 값에 적용하면 약 98,600토큰, OpenAI는 Anthropic의 약 **61%**다.

### 의미가 같은 한·영 문단 (공고 서문)

| 토크나이저 | 한국어 | 영어 | 한국어/영어 |
|---|---:|---:|---:|
| o200k (Luna 계열) | 1,263 | 1,006 | **1.26×** |
| cl100k | 1,986 | 1,017 | 1.95× |
| 구 Claude | 2,232 | 1,042 | 2.14× |

영어에서는 세 토크나이저가 거의 같다(1,006~1,042). 차이는 거의 한국어에서만 난다.

짧은 캘리브레이션 문장(“토큰 사용량을 줄이려고 에이전트 루프를 다시 짰다.” vs 영어 대응): o200k 20 vs 12 (1.67×). 공개 실험과 같은 방향이다.

### 사용자가 쓰는 세 모델

1. **GPT-5.6 Luna** — 이 PDF 전체를 넣으면 입력만 **약 6.0만 토큰**. 세 모델 중 토크나이저가 확인된 유일한 값이다.
2. **Grok 4.6** — 공개 토크나이저 없음. 외부 벤치마크는 Grok 4.6 토크나이저를 o200k와 같은 ‘효율 상위권’으로 둔다. 이 PDF를 Grok 어휘로 직접 세지는 못했다. **Luna와 비슷하거나 약간 적을 가능성**이 있고, Claude처럼 1.5~2배로 튈 근거는 이 측정에 없다. 토큰 단가는 Luna보다 높다.
3. **Composer 2.5** — 공개 토크나이저·카운트 API 없음. 같은 한국어 발췌를 읽히는 서브에이전트는 성공했지만, Cursor 트랜스크립트에 usage 필드가 없어 **이 문서 기준 토큰 수는 미측정**.

### 모델 변경 실측

같은 12,000자 한국어 발췌(o200k 8,176 / 구 Claude 12,535)를 Grok 4.6 High, Composer 2.5, GPT-5.6 Sol Medium이 읽고 `NOTICE_DATE=2026-08-31`만 답했다. GPT-5.6 Luna는 이 에이전트의 서브에이전트 목록에 없어 Sol로 계열 프록시를 돌렸다. 트랜스크립트에 입력·출력 토큰이 없어 청구 사용량 비교는 실패.

이 대화 자체를 Grok 4.6으로 바꿔 가며 재실행하는 것도 Cursor 시스템 프롬프트·도구 정의가 문서보다 클 수 있어, 토크나이저 비교로는 부적합하다.

### 2차 실측 (2026-09-14, 사용자 지정 4모델)

Claude는 제외. 요청은 GPT-5.6 Luna, GPT-5.6 Sol standard, Composer 2.5 standard, Grok 4.6 standard.

병렬 서브에이전트 슬러그: `gpt-5.6-sol-medium`, `composer-2.5`, `cursor-grok-4.6-medium`. 같은 파일 `fixtures/sh-51-longterm-lease-ko.txt`(89,705자)를 읽고 공고일·1순위 기간·콜센터를 JSON으로 쓰게 했다.

| 모델 | 서브에이전트 | 실행 | 공고 사실 추출 | 네이티브 토큰 사용량 |
|---|---|---|---|---|
| GPT-5.6 Luna | 목록에 없음 | 못 띄움 | — | 문서 입력은 Sol과 같은 `o200k`라 **전체 파일 기준 59,755** |
| GPT-5.6 Sol standard | `gpt-5.6-sol-medium` | [실행됨](https://cursor.com/agents/bc-306d77f0-b0a7-5124-913b-1d478126fbf8) | 맞음 | 트랜스크립트에 usage 없음. 전체 파일 기준 **59,755** |
| Composer 2.5 standard | `composer-2.5` | [실행됨](https://cursor.com/agents/bc-e2b0fc67-f558-5b44-928e-b569a99e796c) | 맞음 | usage 없음. 토크나이저 비공개 |
| Grok 4.6 standard | `cursor-grok-4.6-medium` | [실행됨](https://cursor.com/agents/bc-5cd781cc-f5ed-5116-ae9f-2421ccaf0233) | 맞음 | usage 없음. 토크나이저 비공개 |

Luna 슬러그는 이 Task 목록에 없다. 있는 GPT-5.6는 `gpt-5.6-sol-*`, `gpt-5.6-terra-*`뿐이다. Luna를 Sol로 바꿔 띄우지는 않았다.

세 실행 모두 `NOTICE_DATE=2026-08-31`, 1순위 2026-09-14~15, 콜센터 16003456을 맞췄다. `observed_usage`는 전부 `null`이었다. Cursor 서브에이전트 transcript/events에 input·output 토큰 필드가 없다.

`chars_read`는 토큰이 아니다. Sol 64,135(Read 잘림으로 보임), Composer 89,705(파일 길이, 셸로 측정), Grok 102,847(추정, 부정확).

확인된 입력 토큰은 GPT-5.6 계열(Luna=Sol 토크나이저)의 문서 값 **59,755**뿐이다.

### 바로 도움이 된 내용

- 이 공고문 규모는 Luna 계열 입력 약 6만 토큰이다.
- 한국어 페널티는 Luna에서 한·영 대응 문단 기준 약 26%이지, 3~5배가 아니다.
- OpenAI vs Anthropic “50%”는 구 Claude 근사(63%)와 신 Claude 보고(+65% → 약 61%) 사이에 있다.

### 불필요하거나 과도했던 내용

서브에이전트 3회는 날짜 추출은 됐지만 usage를 남기지 않아 토큰 비교에는 쓰이지 못했다.

### 다음 실행에서 바꿀 한 가지

xAI `tokenize_text`와 Anthropic `count_tokens`(Claude 4.7+/Fable)에 같은 추출 텍스트를 넣어 Grok·신 Claude 청구 기준을 직접 잰다. Composer는 Cursor 사용량 UI/API가 열릴 때만 측정 가능하다.
