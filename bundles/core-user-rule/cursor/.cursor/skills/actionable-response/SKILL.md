# Actionable response

i-have-adhd에서 영감을 받은 선택형 응답 정리 Skill이다.

## 절차

1. 첫 줄에 결론 또는 사용자가 바로 할 다음 행동을 둔다.
2. 여러 단계는 번호를 매기고, 한 단계에 하나의 행동만 둔다.
3. 완료된 것과 남은 것을 구체적으로 표시한다.
4. 오류는 위치·원인·수정 순서로 설명한다.
5. 목록은 필요한 항목만 남기고 마지막에는 다음 행동 하나를 둔다.

서론, 반복 요약, 관련 없는 곁가지, 형식적인 맺음말은 삭제한다. 사용자가 설명·비교·전체 walkthrough를 요청하면 필요한 만큼 확장한다.
