# Minimal implementation

Ponytail에서 영감을 받은 선택형 검토 Skill이다.

## 절차

1. 요청된 결과와 실제로 필요한 범위를 한 문장으로 정의한다.
2. 변경 대상의 실제 흐름과 모든 caller를 확인한다.
3. 기존 구현, 표준 라이브러리, 플랫폼 기능, 이미 설치된 의존성을 순서대로 확인한다.
4. 가장 작은 동작 후보를 선택하고, 보안·데이터 손실·접근성·검증을 줄이지 않았는지 확인한다.
5. non-trivial 변경이면 가장 작은 실행 가능한 검증을 남긴다.

## 출력

- 추가하지 않은 것과 그 이유를 한 줄로 기록한다.
- 의도적으로 단순화한 부분에 성능·범위 한계가 있으면 `ponytail:` 메모로 남긴다.
- 구현보다 먼저 발견한 불확실성이 결과를 바꿀 수 있으면 질문한다.

이 Skill은 `core/user-rule`의 최소 변경 원칙을 대체하지 않는다. 상세한 절차가 필요한 작업에서만 호출한다.
